## What the experiment does well

- The dev2 alpha-selection rule is committed before the dev2 selection result, and prompt v3 is frozen before the test-arm generation commits (`0907083`, `68dd98f`, `4a8782f`, `8d00a33`).
- Arms use the same answerable test questions, and the primary arm comparisons use exact paired McNemar tests with a stated 60-test Holm family; the handover correctly reports no Holm-significant result.
- Generation records preserve useful run identifiers, including model digest, prompt hash, seed, Ollama version, and packing metadata.
- The answerable output is prepared for blinded human judgment, separate from the automated faithfulness scoring.
